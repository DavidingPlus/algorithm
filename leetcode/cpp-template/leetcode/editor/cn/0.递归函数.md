# C++ 递归函数的三种实现方式

参考 322 题。

## 1. 普通递归函数

最传统、最直观的递归实现方式，直接通过函数名调用自身。

```cpp
int dfs(std::vector<int>& coins, int remain, int INF)
{
    if (remain == 0) return 0;

    int res = INF;

    for (int coin : coins)
    {
        if (coin <= remain)
            res = std::min(res, 1 + dfs(coins, remain - coin, INF));
    }

    return res;
}

int coinChange(std::vector<int>& coins, int amount)
{
    const int INF = amount + 1;
    int res = dfs(coins, amount, INF);

    return res == INF ? -1 : res;
}
```

**特点：**
- 直接通过函数名调用自身，不需要额外参数。
- 实现简单，易于理解和维护。
- 需要将递归函数定义在独立的函数作用域中，不能直接定义为普通的局部函数。

## 2. std::function Lambda

利用 `std::function` 显式声明函数类型，使 Lambda 能够在函数体内调用自身。

```cpp
#include <functional>

int coinChange(std::vector<int>& coins, int amount)
{
    const int INF = amount + 1;

    std::function<int(int)> dfs = [&](int remain) -> int
    {
        if (remain == 0) return 0;

        int res = INF;

        for (int coin : coins)
        {
            if (coin <= remain)
                res = std::min(res, 1 + dfs(remain - coin));
        }

        return res;
    };

    int res = dfs(amount);

    return res == INF ? -1 : res;
}
```

**特点：**
- `std::function<int(int)>` 显式声明了函数类型，解决了递归调用时的类型推导问题。
- Lambda 可以直接使用 `dfs()` 调用自身。
- 可以在局部作用域中定义递归函数。
- `std::function` 存在类型擦除带来的额外开销。

## 3. 泛型 Lambda（C++14）

通过 `auto&& self` 显式传递 Lambda 自身，实现递归调用，不需要使用 `std::function`。

```cpp
int coinChange(std::vector<int>& coins, int amount)
{
    const int INF = amount + 1;

    auto dfs = [&](auto&& self, int remain) -> int
    {
        if (remain == 0) return 0;

        int res = INF;

        for (int coin : coins)
        {
            if (coin <= remain)
                res = std::min(res, 1 + self(self, remain - coin));
        }

        return res;
    };

    int res = dfs(dfs, amount);

    return res == INF ? -1 : res;
}
```

### 3.1 self 是什么？

`self` 不是 C++ 关键字，而是一个普通的参数名。

```cpp
auto dfs = [&](auto&& self, int remain) -> int
```

其中：
- `auto`：由编译器自动推导参数类型。
- `&&`：转发引用，在这里用于接收 Lambda 自身。
- `self`：保存传入的 Lambda 对象，可以通过它调用当前 Lambda。

### 3.2 为什么需要显式传递自身？

第一次调用：

```cpp
int res = dfs(dfs, amount);
```

这里将 `dfs` 自身作为第一个参数传入，因此 `self` 就引用了当前 Lambda 对象。

递归调用：

```cpp
self(self, remain - coin);
```

相当于再次调用当前 Lambda，并将自身继续传递下去。

可以理解为：

```cpp
dfs(dfs, amount);
dfs(dfs, remain - coin);
dfs(dfs, remain - coin - coin);
```

### 3.3 为什么不能直接在 Lambda 内部调用 dfs？

可能会想到下面这种写法：

```cpp
auto dfs = [&](int remain) -> int
{
    if (remain == 0) return 0;

    return dfs(remain - 1);
};
```

这种写法在 C++ 中是不合法的。

**原因：**

`auto dfs = ...` 需要根据右侧的 Lambda 表达式推导 `dfs` 的类型。

但是在 Lambda 初始化表达式内部，`dfs` 的类型推导尚未完成。

此时直接使用 `dfs()` 递归调用自身，就会形成类型推导上的循环依赖：

1. 编译器需要推导 `dfs` 的类型。
2. 推导类型需要分析 Lambda 表达式。
3. Lambda 函数体中又需要使用 `dfs`。
4. 但此时 `dfs` 的类型尚未推导完成。

因此编译器无法完成类型推导。

**解决方式：**

- 使用 `std::function` 显式声明函数类型。
- 使用泛型 Lambda，通过 `self` 参数显式传递自身。

### 3.4 泛型 Lambda 的优势

- 不需要 `std::function`。
- 不需要类型擦除。
- 编译器可以在编译期确定具体调用类型。
- 适合将 DFS、回溯、记忆化搜索等递归逻辑封装在局部作用域中。

## 4. 三种方式对比

| 对比项 | 普通递归函数 | std::function Lambda | 泛型 Lambda |
|---|---|---|---|
| 递归调用 | `dfs(...)` | `dfs(...)` | `self(self, ...)` |
| 是否需要额外参数 | 否 | 否 | 是 |
| 是否支持局部定义 | 否 | 是 | 是 |
| 类型擦除 | 无 | 有 | 无 |
| 实现复杂度 | 低 | 低 | 中 |

## 5. 如何选择？

1. **普通递归函数**：优先选择，适合一般递归问题，代码直观。
2. **std::function Lambda**：适合希望在局部作用域定义递归函数，同时更看重代码可读性的场景。
3. **泛型 Lambda**：适合希望在局部作用域定义递归函数，同时避免 `std::function` 类型擦除开销的场景。

**核心记忆：**

- 普通函数：通过函数名调用自身。
- `std::function`：通过提前声明函数类型，让 Lambda 能够调用自身。
- 泛型 Lambda：通过 `auto&& self` 显式传递自身，使用 `self(self, ...)` 实现递归。

对于 LeetCode 中的 DFS、回溯和记忆化搜索，建议掌握普通递归函数和泛型 Lambda 两种方式。
